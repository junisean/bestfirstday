# 현재 기능

직원 이름, 준비서류·복장·규정·비상연락처 (이슈발생시)·찾아오는 길 항목 편집, 네이버 플레이스 링크, 직원 전용 안내, 전체 항목 확인 조건, 최종 확인 기록 서버 저장, 사장님 전용 확인 현황.

최신 실행 소스는 worker/index.js와 worker/content.js입니다.

최종 확인 버튼 문구: 모든 사항을 확인하고 5분전 도착할 예정입니다

이름·확인 시각·확인한 안내 내용을 R2 confirmations/에 저장합니다. 같은 안내의 중복 확인은 한 건으로 유지합니다. 안내 링크에 입력된 이름을 사용하며 별도 직원 본인인증은 없습니다. 기존에 배포한 정적 페이지와 달리 현재는 확인 완료가 서버에 저장됩니다.
